## Emerging Non-Volatile Memory

My research focuses on emerging non-volatile memory devices and their integration in advanced semiconductor technologies.

## Embedded Memory

I am interested in embedded RRAM, FeRAM, MRAM, and PCRAM for low-power and high-density memory applications.

## Device-Circuit Co-Design

I also work on device-circuit co-design methodologies for memory arrays and in-memory computing systems.
